# Plantillas de Domi

Crea cuadernos y plantillas de notas (PDF vectorial y PNG) a la medida de tablets Samsung Galaxy Tab S9–S12, para importar en Samsung Notes.

- Tipos de hoja: rayada, cuadros, puntos, Cornell, idiomas, en blanco
- Papel blanco, sepia, gris u oscuro · color de detalles a elección
- Portada (4 diseños) e índice · numeración continuable
- Interfaz y plantillas en español, inglés y lituano
- Funciona sin internet una vez instalada (PWA)
